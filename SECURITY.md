# Security Policy

Please do not disclose vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository when enabled, or contact the maintainers through the organization's published security channel.

Supported security fixes target the latest minor release. Reports should include affected version, reproduction steps, impact and any known mitigation.

QKTestAnalytics reports may contain screenshots, videos, logs, stack traces, URLs and arbitrary test metadata. Treat generated reports as potentially sensitive CI artifacts. The renderer must escape untrusted text and must not execute test-result content as code.
